# @uoacs/shared

Non-UI code that more than one UOACS app needs: the auth client and session helpers, auth route
constants, cross-app Payload types and Zod schemas, the Discord widget client and small utilities.

The package ships raw TypeScript — there's no build step. Apps compile it by listing it in
`transpilePackages` in their `next.config.ts`.

## Exports

| Entry point | Environment | Contents |
|-------------|-------------|----------|
| `@uoacs/shared` | Any | Auth routes, pages and `authPageUrl()`; auth form schemas; session types; Discord widget; Payload collection slugs; `shuffle()`; `downscaleImage()` (browser only) |
| `@uoacs/shared/auth` | Client | `authClient` (the single Better Auth client) and session types |
| `@uoacs/shared/auth/server` | Server only | `getSession()` and `sessionFetch()` |
| `@uoacs/shared/payload` | Any | Payload types generated by `apps/auth`, `richTextFeatures`, the member schema and slugs |

## Auth

All apps sign in through the hosted auth service in [`apps/auth`](../../apps/auth/README.md). 
Everything needed to talk to it lives here, so apps can't drift apart:

```ts
// Link to a hosted auth page, returning to the current page afterwards
import { AuthPages, authPageUrl } from "@uoacs/shared"
const href = authPageUrl(AuthPages.LOGIN, "https://projects.example.com/profile")

// Read the session in a server component, route handler or action
import { getSession } from "@uoacs/shared/auth/server"
const result = await getSession()
if (result.status === "authenticated") {
  result.session.user
}

// Client-side Better Auth calls
import { authClient } from "@uoacs/shared/auth"
```

- `getSession()` calls the auth service over the network, replaying the person's cookie, and is cached
  per request. It returns `authenticated`, `unauthenticated` or `unavailable` — treat `unavailable` as
  "unknown", not as signed out.
- `AuthApiRoutes` and `AuthPages` mirror route directories in `apps/auth`. Renaming a route there means
  updating it here.
- `NEXT_PUBLIC_AUTH_URL` must be set in any app that uses these helpers.

## Payload types

`src/payload/payload-types.ts` is **generated by `apps/auth`** (`pnpm --filter @uoacs/auth
types:generate`) — don't edit it by hand. It describes the member data auth owns, which the website and
playground consume through the auth API.

## What belongs here

Code shared by two or more apps that isn't UI. Components go in
[`@uoacs/ui`](../ui/README.md); code only one app uses stays in that app.
